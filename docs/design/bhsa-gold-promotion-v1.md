# Design: first six adjudicated official tutorial gold pairs (#10)

- **Gold data:** Extend existing `benchmarks/nl-tf-v1/bhsa-2021.json` with six supported `train`/`development` records, each copying exactly the native query and real 2021 observed count from the existing candidate fixture/report and supplying a narrower NL request + equivalence rationale. Do not alter any existing evaluation case or existing native gold records. This remains format version 1; all source checks stay strict. Extend `PINNED_FILES` to include `qere.tf` and `book.tf`.
- **Typed witnesses:** Maintain `scripts/bhsa_gold_ir.py` with immutable, explicit `Query` instances keyed by promoted benchmark case ID. All symbols, predicates and relations must pass the actual loaded API symbol/value checks. Test the mapping is exhaustive for the six intended promoted cases and does not include evaluation records or any arbitrary raw query.
- **Native corpus gate:** On every dedicated replay workflow, after source verification and gold counts, compile the six witnesses using `NativeSymbols` backed by the same loaded TF instance (research harness already exists at `tests/test_compiler.py`). Compare complete **native result tuples**, not merely counts, using `scripts.nl_benchmark.equivalent()`, with one-extra-row limit and diagnostic handling. Do not use self-referential hand-authored expected node lists or a homegrown execution engine.
- **Regression unit tests:** Initially RED for absent new gold IDs / nonexistent witness module. Verify no test split promotions, precise gold counts, `qere` present vs literal `qere=absent` distinction, witness connectivity, exact approved IDs and source file pinning. Assert compilation on tiny corpus where available, and independent full-tuple native replay on real BHSA via the new scoped workflow.
- **Durable report:** Existing native replay report `gold_checked` changes to 12 and `gold_fixture_sha256` changes; refresh those fields in `native-observations-2021.json` from actual run, never change its 14 candidate observations. Until reference is aligned the scoped native job is expected to reject the old reference, by design. Produce the new SHA256 in the workflow through a transparent sha256sum step for review.
- **Non-goals:** Do not claim model accuracy, LLM parser ability, total 100-case benchmark, or evidence for non-promoted queries. No changes to the generic compiler or Text-Fabric grammar are planned.
